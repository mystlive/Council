### 承認の根拠

評議会推奨（`runs/private/RUN-20260929-0001/attempt-01/final_synthesis.md`）の提示後、人間が「AI提案を出してそれで実装してみて下さい」と指示した（2026-09-29）。本決定は、その指示に基づき Council Runner が作成した AI 提案（`runs/private/RUN-20260929-0001/attempt-01/ai_proposal.md`、HD-2: 基本線B、HD-4・HD-5・HD-9）の採用範囲を記録する。

### 決定内容

1. IMP-01: `hooks/validate.py` の attempt 抽出正規表現（二重エスケープで常に不一致）を修正し、ATTEMPT_MISMATCH の回帰テストを追加した。
2. ALT-04: Stop Hook（pre-decision）が Hook 入力を読み、RUNNING 中は BLOCK するが、`stop_hook_active` かつ前回 BLOCK から進展がない再停止は警告で許可する。24時間更新のない RUN は STALE として警告し、`hooks/runner.py release` で解除できる。`.claude/settings.json` に `CLAUDE_CODE_DISABLE_BACKGROUND_TASKS=1` を設定した（HD-5）。OpenTelemetry は無効のまま。
3. IMP-02（再定義）: PreToolUse/PostToolUse の matcher に PowerShell を追加し、コマンド検査を Bash と PowerShell の両方に適用した。書込み判定をリダイレクト先の解析と書込み系コマンド（cp、mv、Copy-Item、shutil、write_text、git checkout 等）の検出に改め、`2>/dev/null` や読取コマンドの誤検知を解消した。保護ファイルはセッション開始時のハッシュ基準線と照合し、ツールに依存せず改変を検知する（ALT-03）。基準線の更新は人間専用。
4. IMP-03: RUN-ID を `RUN-YYYYMMDD-NNNN`（ローカル日付、日単位採番、既存ディレクトリは飛ばす）で発行する。
5. IMP-04: research_mode は chair-review への遷移時に確定する。`audit_revisions` は差し戻し後の再監査の回数とし、初回監査では加算しない。予算・カウンタの bool を拒否する。工程遷移を `runs/private/<RUN-ID>/transition_log.jsonl` に永続化し、`runner.py start|apply|release` を追加した。
6. IMP-07a: SessionStart で実行中の Claude Code の版（`CLAUDE_CODE_EXECPATH` から取得、2026-09-29 時点で 2.1.284）、entrypoint、session effort、各 Subagent の model/effort を `.council/runtime_fingerprint.json` に記録し、版変化・model 強制設定を警告する。
7. IMP-15: 秘密情報検出に AWS・Google API・Slack のキー形式を追加し、`.env.*`（.example 等を除く）への書込みを拒否する。
8. HD-9: `.claude/settings.local.json` から `Bash(git push *)`、`Bash(env)`、`Bash(python -)`、`Bash(python3 -)`、`Bash(python -c ' *)` の事前許可を削除した（変更前のファイルはセッションの scratchpad に退避）。
9. HD-4: デスクトップアプリ内蔵の Claude Code を評議会の正式な実行経路とする。
10. IMP-05: STATE.md、README.md/README.en.md、_index.md、docs/runtime-hardening-design.md、hooks/README.md を現況に同期した。

### 採用理由

- 本RUNで観測した障害（Stop Hook の待機中 BLOCK 2回、書込み検出の誤検知 2回）と、コードで確認した欠陥（PowerShell 迂回、attempt 検査の無効化、RUN-ID 形式不一致、監査カウンタの定義ずれ）は、モデル性能に依存せず、安価に直せる。
- モデル割当の効果を事後評価するには、実行版と役割設定の記録が前提になる。
- 検証: Hook テスト 93 件 PASS、pre-run PASS、一時ディレクトリでの E2E（RUN 開始 → 監査差し戻し → 再監査 → 完了、および不正な直接編集の検知）PASS、PowerShell ツールへの Hook 適用を実機で確認。
